# TikTok Quality Optimizer

A starter web app for:
1. Uploading a video
2. Processing it with FFmpeg
3. Downloading the optimized output

## Requirements
- Node.js 18+
- FFmpeg installed and available as `ffmpeg` in PATH

## Run
```bash
npm install
npm start
```
Then open http://localhost:3000

## TikTok posting
This starter intentionally does not include unofficial TikTok login/upload automation.
Use TikTok's official Content Posting API after creating a TikTok developer app and obtaining the required permissions.
